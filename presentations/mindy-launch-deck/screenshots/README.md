## Rules
- **Format:** `.png` only.
- **Name exactly** as listed below — the build matches `screenshots/<name>.png`.
- **Partial is fine** — add whatever you have; missing ones stay as "📸 Drop screenshot" placeholders.
- After adding files, run: `node presentations/build-master.js` (inlines every match + reports real vs. placeholder).

## Capture tips
- Frames crop to a **wide banner** (`object-fit: cover`, **top-aligned**) — the *top* of the image is what shows.
- Feature shots render ~**880×382**; one-box / lineage shots ~**760** wide. Landscape browser captures work best.
